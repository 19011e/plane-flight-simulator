# Sky Runner

A simple browser-based airplane flight simulator built with Three.js.

## Features
- 3D airplane model
- Basic flight physics
- Pitch, roll, yaw controls
- Throttle and braking
- Follow camera
- Simple HUD with speed and altitude

## Run it locally
From the project folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Controls
- W / S: throttle
- A / D: yaw left / right
- Arrow Up / Down: pitch up / down
- Arrow Left / Right: roll left / right
- Space: brake

## Notes
This is intentionally a lightweight prototype designed to be easy to run and extend.
